# Curso em Vídeo - Python Course

This folder contains all the exercises and notes from the **Python 3 course** by [Curso em Vídeo](https://www.cursoemvideo.com/) (taught by Gustavo Guanabara). It is one of the most popular and beginner-friendly Python courses in Portuguese.

## 🧠 Course Overview

The course is divided into video lessons and practical exercises that cover:

- Basic Python syntax
- Variables and data types
- Conditionals and loops
- Functions
- Lists and dictionaries
- Modules and packages
- File handling
- Introduction to object-oriented programming

## 📁 Structure

Each file or folder inside represents a lesson or a group of exercises, following the original course order.

## 🎯 Goal

My goal with this course was to build a strong foundation in Python programming by practicing consistently.
