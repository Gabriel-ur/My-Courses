# Data Science Academy

This folder contains all the projects and exercises from the Data Science Academy course. It is a comprehensive program focused on data science, machine learning, and data analysis using Python.

## 🧠 Course Overview

The course covers topics such as:

- Data manipulation and cleaning  
- Statistical analysis  
- Data visualization  
- Machine learning algorithms  
- Big data tools and techniques  
- Python libraries like pandas, numpy, matplotlib, scikit-learn  

## 📁 Structure

Each file or folder inside represents a project or a set of exercises, organized according to the course modules.

## 🎯 Goal

My goal with this course was to develop practical skills in data science by applying concepts in real-world projects and exercises.

All code is written and tested by me as part of my learning journey.
